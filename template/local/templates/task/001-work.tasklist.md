# 실행·완료 체크리스트

- [ ] 목표·범위·완료 기준·관련 설계 확인
- [ ] C0: base·worktree·owned/shared/excluded·active issue 확인
- [ ] 구현·조사 계획과 검증 방법 기록
- [ ] C1: 계약·정책 변경의 downstream 영향 확인
- [ ] C2: 공용 파일 작성자 확인 (해당 없음이면 이유 기록)
- [ ] 구현과 필요한 검증 완료
- [ ] C3: 범위 밖 회귀·다른 worktree 영향 확인
- [ ] C4: staged/unstaged/untracked·관련 issue·비밀값·생성물 확인
- [ ] handoff: 검증·branch·SHA·push·PR·main·배포·남은 위험 기록
- [ ] 태스크 DONE 이동 및 progress 갱신

완료 체크는 실제 증거와 함께 기록한다. 미실행은 미실행으로 표시한다.
