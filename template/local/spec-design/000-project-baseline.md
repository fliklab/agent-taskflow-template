# 프로젝트 장기 기준

프로젝트 시작 시 아래 항목을 실제 상황으로 채운다. 확정하지 못한 내용은 추정하지 않고 미결정으로 표시한다.

- 목적과 대상 사용자:
- 이번 범위 / 제외 범위:
- 핵심 사용자 여정과 완료 기준:
- 저장소 구조와 기술 선택의 이유:
- 데이터·인증·권한 경계:
- 외부 서비스와 환경 구분:
- 배포·복구·인수 담당자:
- 단계별 진행 계획:
- 확정 결정 / 미결정 질문 / 위험과 해제 조건:

규모가 커지면 요구사항, 구조, 데이터, 권한, 화면, 연동, 로드맵, 결정·위험을 별도 문서로 분리한다.
문서는 실제 코드·검증과 다르면 차이와 후속 태스크를 함께 남긴다.
